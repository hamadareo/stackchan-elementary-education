# 現場(教室)での使い方 — 先生向け

StackChan 3台で、子どもたちと遊ぶための手順です。Wi-Fi は使いません。**hamada(Ubuntu のパソコン)と StackChan 3台を、USB ケーブルでつなぎます。**

## 1. 準備(授業の前)
1. **電源つきの USB ハブ**(セルフパワー)を、hamada につなぎます。3台を、そのハブにつなぎます。パソコンの USB だけだと、電力が足りなくて切れることがあります。
2. **どの差し口でも大丈夫です**。機器は、差し口ではなく、機器の ID で見分けます。差し替えても、同じ機器として動きます。
3. hamada の電源を入れます。ブリッジ・声(VOICEVOX)・ローカル AI は、自動で起動します(約1分)。
4. hamada の画面の管理アプリ(「StackChan」)を開きます。機器が3台、「USB 有線」でオンラインになれば準備完了です。
5. インターネットにつながっているときは、自動で s109(高速サーバー)を使い、つながっていなければ hamada 単体で動きます(返事は少し遅くなります)。

## 2. 遊びを始める
1. 管理アプリの「教材」タブで、**教材モード**にチェックを入れます(翻訳・3人会話・自律会話が止まります)。
2. **ロボットは、子どもが遊びを選ぶまで、自分からは話しません。**子どもに「あそぼう」と言わせると、遊びを案内します。
3. 子どもが言う言葉(出す遊びは、教材タブのチェックで変えられます):

| 遊び | 言う言葉 | ロボットの動き |
|---|---|---|
| しりとり | 「しりとりしよう」 | ロボットから始める |
| じゃんけん | 「じゃんけんしよう」 | 声、またはカメラで手を見て判定(手を20〜30cmに、大きくかざす) |
| なぞなぞ | 「なぞなぞしよう」 | 5問。「ヒント」「わからない」も言える |
| あっち向いてホイ | 「あっちむいてホイしよう」 | じゃんけんのあと、首を向けて指さす |
| おみくじ | 「おみくじ」 | 「ガラガラ…」のあと、運勢を言う |
| ものまねボイス | 「ものまねしよう」 | 言った言葉を、いろいろな声でまねする |

4. やめるときは、「やめよう」「おわり」と言います。管理アプリの「やめる」でも止められます。
5. 機器の画面には、じゃんけんの手・おみくじの結果などが、大きく出ます(画面表示に対応した更新が済んでいる機器のみ)。

## 3. 声が聞き取れないとき(先生の助け)
- 教材タブの各遊びのカードに、**先生の入力欄**があります。子どもの代わりに、答えや手を入れられます。
- じゃんけんは、「手の確認」(カメラ映像と、検出された手)を、管理アプリで見られます。

## 4. うまくいかないとき
| 症状 | 確認すること |
|---|---|
| 機器がオンラインにならない | USB ケーブルを挿し直す。ハブの電源を確認する。それでも出ないときは、機器のリセット(RST)ボタンを押す |
| 機器が時々切れる | セルフパワーのハブにする。ケーブルを短く・データ通信対応のものに |
| ロボットが話さない | 教材モードでは、遊びを選ぶまで話しません。「あそぼう」と言わせてみる。音量は管理アプリで確認する |
| 返事が遅い | インターネットなしで、3台が同時に話しかけると遅くなります(順番待ち)。1台ずつ話しかけてもらう |
| 子どもの声に反応しない | 機器に近づいて話してもらう。うるさい場所では、先生の入力を使う |
| 画面に結果が出ない | 機器のプログラムが古い。次の「ファームウェアの更新」を行う |

## 5. 機器のプログラム(ファームウェア)を更新する
Mac で更新版を作って、hamada に配ります(`bash deploy/ubuntu/deploy.sh`)。そのあと、hamada の管理アプリの「機器」タブの**「USB の機器を更新する」**を押します。つながっている機器が、1台ずつ(約1分)更新されます。更新中は USB を抜かないでください。更新する機器だけをつなぐと、確実です。

## 6. 授業のあと
- 管理アプリで教材モードを切ると、ふつうの通訳・3人会話に戻ります。
- 3台の USB を抜くだけで終了できます。hamada は、そのままシャットダウンして構いません。
