# 現場(教室)での使い方 — 先生向け

StackChan 3台で、子どもたちと遊ぶための手順です。Wi-Fi は使いません。**hamada(Ubuntu のパソコン)と StackChan 3台を、USB ケーブルでつなぎます。**

## 1. 準備(授業の前)
1. **電源つきの USB ハブ**(セルフパワー)を、hamada につなぎます。3台を、そのハブにつなぎます。パソコンの USB だけだと、電力が足りなくて切れることがあります。
2. **どの差し口でも大丈夫です**。機器は、差し口ではなく、機器の ID で見分けます。差し替えても、同じ機器として動きます。
3. hamada の電源を入れます。ブリッジ・声(VOICEVOX)・ローカル AI は、自動で起動します(約1分)。
4. hamada の画面の管理アプリ(「StackChan」)を開きます。機器が3台、「USB 有線」でオンラインになれば準備完了です。
5. インターネットにつながっているときは、自動で s109(高速サーバー)を使い、つながっていなければ hamada 単体で動きます(返事は少し遅くなります)。

## 2. 遊びを始める・中止する(先生が、管理アプリで操作します)
管理アプリの**「授業」タブ**が、授業の操作画面です。機器ごとに、1枚のカードがあります。

1. 「授業モード」にチェックが入っていることを確認します(既定でオンです。オンの間、**ロボットは、先生がボタンを押すまで何も話さず、何もしません**。翻訳・3人会話・自律会話も止まります)。
2. 遊ばせたい機器のカードで、遊びのボタンを押します。**押したその機器で、すぐ始まります**。全部の機器でいっせいに始めるときは、上の「全台でいっせいに」のボタンを使います。
3. 6つの遊び: しりとり / じゃんけん / なぞなぞ / おみくじ / ものまねボイス / ずんだの チャリはしり。(あっちむいてホイは、分かりにくいので外した)
4. **「■ 中止」**を押すと、その機器の遊びも声も、**すぐ止まります**。そのまま、次の遊びのボタンを押せます。遊びの途中で別の遊びのボタンを押すと、いまの遊びを止めて、すぐ切り替わります。「■ 全部中止」は、全機器を止めます。
5. 子どもが「あそぼう」「じゃんけんしよう」と言っても、遊びは始まりません(先生のボタンだけで始まります)。子どもの声でも始められるようにしたいときは、「授業モード」のチェックを外します。
6. 子どもが遊びの答え・手・言葉を言うのは、遊びが始まったあとです。カードの下に、「子どもに言ってもらうこと」が出ます。

| 遊び | 子どもが言う・すること | ロボットの動き |
|---|---|---|
| しりとり | 言葉を言う | ロボットから始める |
| じゃんけん | 「ぐー・ちょき・ぱー」を言う、または、カメラに手をかざす | 声、またはカメラで手を見て判定 |
| なぞなぞ | 答えを言う(「ヒント」「わからない」も言える) | 5問 |
| ずんだの チャリはしり | 機器の画面の中で、自転車のずんだもんが走る。画面タッチ・天面(頭のてっぺん)タッチ・実際のジャンプ(カメラ)・声の「ジャンプ」のどれでも、ジャンプして、いわ・コーン・はこをよける。ぶつかると、走った距離(メートル)と記録を言う。もう一度タッチで再スタート | 画面だけ(首は動かさない) |
| おみくじ | 「やる」「やめる」 | 「ガラガラ…」のあと、運勢を言う |
| ものまねボイス | まねしてほしい言葉を言う | いろいろな声でまねする |

7. 機器の画面には、じゃんけんの手・おみくじの結果などが、大きく出ます(画面表示に対応した更新が済んでいる機器のみ)。

### カメラを使う遊び(じゃんけんは手、あっちむいてホイは顔の向き)
子どもが近すぎる・遠すぎる・顔や手が見えない・暗いときは、**ロボットが声と機器の画面で、「すこしさがってね」などと、子どもに教えます**。教えても直らないときは、「こえでおしえてね」と言って、声だけで進めます。いまの見え方は、授業タブのカードの「カメラ:」に出ます。

## 3. 声が聞き取れないとき(先生の助け)
- 授業タブの各カードに、**先生の入力欄**があります(どの遊びでも使えます)。子どもの代わりに、答えや手を入れられます。
- じゃんけんは、「手の確認」(カメラ映像と、検出された手)を、管理アプリで見られます。

## 4. うまくいかないとき
| 症状 | 確認すること |
|---|---|
| 機器がオンラインにならない | USB ケーブルを挿し直す。ハブの電源を確認する。それでも出ないときは、機器のリセット(RST)ボタンを押す |
| 機器が時々切れる | セルフパワーのハブにする。ケーブルを短く・データ通信対応のものに |
| ロボットが話さない | 授業モードでは、先生が授業タブのボタンを押すまで話しません。音量は管理アプリで確認する |
| 返事が遅い | インターネットなしで、3台が同時に話しかけると遅くなります(順番待ち)。1台ずつ話しかけてもらう |
| 子どもの声に反応しない | 機器に近づいて話してもらう。うるさい場所では、先生の入力を使う |
| 画面に結果が出ない | 機器のプログラムが古い。次の「ファームウェアの更新」を行う |

## 5. 機器のプログラム(ファームウェア)を更新する
Mac で更新版を作って、hamada に配ります(`bash deploy/ubuntu/deploy.sh`)。そのあと、hamada の管理アプリの「機器」タブの**「USB の機器を更新する」**を押します。つながっている機器が、1台ずつ(約1分)更新されます。更新中は USB を抜かないでください。更新する機器だけをつなぐと、確実です。

## 6. 授業のあと
- 管理アプリで教材モードを切ると、ふつうの通訳・3人会話に戻ります。
- 3台の USB を抜くだけで終了できます。hamada は、そのままシャットダウンして構いません。
